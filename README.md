# SelfCheck Pro — сайт

Статический сайт, деплоится автоматически при пуше в GitHub. Сборки нет, править можно прямо в HTML.

## Структура

```
index.html              главная
horeca.html             /horeca      кафе, рестораны и бары
uk.html                 /uk          управляющие компании
posutochno.html         /posutochno  посуточная аренда
klining.html            /klining     клининговые компании
policy.html             /policy      политика обработки персональных данных
consent.html            /consent     согласие на обработку данных

assets/styles.css       общие стили всех страниц
logo.png                логотип
favicon-32.png          иконка вкладки
apple-touch-icon.png    иконка на экране телефона
og.png                  превью для мессенджеров и соцсетей

functions/api/lead.js   серверная функция: принимает заявку и шлёт в Telegram
robots.txt, sitemap.xml для поисковиков
```

Стили лежат в одном файле, поэтому правка дизайна применяется сразу ко всем страницам. Тексты у каждой страницы свои.

## ЗАПОЛНИТЬ, КОГДА ПОЯВИТСЯ ИП

Реквизиты нужны в двух файлах: `policy.html` и `consent.html`. В `policy.html` они собраны в одном блоке в начале страницы, в `consent.html` упоминаются в первом абзаце.

Найти по слову `fill` и заменить:

| Что | Где искать |
|---|---|
| `ИП Фамилия Имя Отчество` | policy.html, consent.html |
| `000000000000` (ИНН) | policy.html, consent.html |
| `000000000000000` (ОГРНИП) | policy.html |
| `индекс, город, улица, дом` | policy.html |
| `__.__.2026` (дата редакции) | policy.html, consent.html |

После заполнения убрать у этих мест `class="fill"` — она подсвечивает незаполненное жёлтым. Пример:

```html
<!-- было -->
<span class="fill">ИП Фамилия Имя Отчество</span>
<!-- стало -->
ИП Иванов Иван Иванович
```

До заполнения страницы закрыты от индексации (`noindex`), но открываются по ссылке. Собирать заявки без них нельзя: этого требует 152-ФЗ.

## Шаг 1. Завести Telegram-бота

1. В Telegram написать [@BotFather](https://t.me/BotFather), отправить `/newbot`, придумать имя и логин бота. В ответ придёт **токен** вида `1234567890:AAH...`
2. Создать группу для заявок, добавить в неё бота. Если хотите получать заявки лично — просто напишите боту `/start`
3. Отправить в этот чат любое сообщение и открыть в браузере:
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   Найти в ответе `"chat":{"id":...}` — это **chat_id**. У групп он отрицательный, это нормально

Проверить, что бот пишет в чат, можно одной командой в терминале:

```bash
curl "https://api.telegram.org/bot<ТОКЕН>/sendMessage" \
  -d chat_id=<CHAT_ID> -d text="Проверка связи"
```

Если сообщение пришло — бот готов.

## Шаг 2. Положить в GitHub

Создать репозиторий на github.com и загрузить содержимое этой папки: кнопка **Add file → Upload files**, перетащить всё, **Commit**.

Через терминал:

```bash
cd путь/к/папке
git init && git add . && git commit -m "Сайт SelfCheck Pro"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/selfcheck-site.git
git push -u origin main
```

## Шаг 3. Подключить Cloudflare Pages

1. [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages → Create → Pages → Connect to Git**
2. Выбрать репозиторий
3. Настройки сборки: **Framework preset** — None, **Build command** — пусто, **Build output directory** — `/`
4. **Save and Deploy**. Через минуту появится адрес `имя-проекта.pages.dev`

## Шаг 4. Прописать токен бота

**Settings → Environment variables**, окружение Production:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из шага 1, нажать Encrypt |
| `TELEGRAM_CHAT_ID` | chat_id из шага 1 |

Затем **Deployments → Retry deployment**, иначе переменные не подхватятся. Отправить тестовую заявку с сайта и проверить чат.

Если заявка не пришла: **Deployments → выбрать деплой → Functions → Logs**, там будет причина.

## Шаг 5. Домен

**Custom domains → Set up a domain** → `selfcheck.pro`. Cloudflare подскажет, какие записи прописать у регистратора. SSL выпустится сам.

Кабинет сервиса стоит увести на `app.selfcheck.pro` — ссылки «Войти» в шапке и футере уже ведут туда.

## Как дорабатывать

Правка в файле → пуш в `main` → сайт обновился за минуту. Откат делается из истории деплоев одной кнопкой. Для крупных изменений удобно завести ветку: Cloudflare соберёт её на отдельной ссылке, не трогая боевой сайт.

Заявки помечаются разделом, откуда пришли, поэтому в Telegram сразу видно, какая ниша даёт результат.

## Что осталось

- **Реквизиты ИП** в policy.html и consent.html — см. блок выше
- **Цена базового тарифа**: стоит заглушка `0 000 ₽`
- **Кейсы в блоке «Для кого»** вымышленные, заменить после первых пилотов
- **Аналитика**: перед `</body>` вставить счётчик Яндекс.Метрики на всех страницах
- **Шрифт Poppins** грузится с Google Fonts. Если из России медленно — положить файлы шрифта в `assets` и подключить через `@font-face`
- **Логотипы клиентов** появятся после пилотов, под них можно вернуть полосу на главной
